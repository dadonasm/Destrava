Como iniciar nesta máquina

Roda direto, sem pendrive. O programa vai para uma pasta temporária e é apagado ao terminar.

Windows

Abra o PowerShell (menu Iniciar → digite PowerShell) e cole:

irm {{ servidor }}/iniciar.ps1 | iex

Mac e Linux (Zorin)

Abra o Terminal e cole:

curl -fsSL {{ servidor }}/iniciar.sh | sh

O que acontece

  1. O programa pede a chave do técnico.
  2. Baixa o Destrava! e um Python fixo para uma pasta temporária, conferindo cada arquivo.
  3. O técnico faz o atendimento pelo navegador.
  4. No fim, Encerrar apaga tudo desta máquina.

Fichas, históricos e termos de autorização ficam no servidor da loja, não nesta máquina. Os arquivos pessoais não são enviados: só o resumo da análise e os registros do serviço.
